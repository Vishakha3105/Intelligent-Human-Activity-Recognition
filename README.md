# Intelligent Human Activity Recognition with Digital Twin

An academic research project exploring **Human Activity Recognition (HAR)** for healthcare through the integration of **Internet of Healthcare Things (IoHT)**, **Artificial Neural Networks (ANN)**, and **Digital Twin** concepts.

## Overview

Human Activity Recognition focuses on identifying and analysing a person's activities using activity-related data. This project explores how intelligent recognition techniques can be considered within an IoHT environment and connected with a Digital Twin approach.

A Digital Twin is a virtual representation of a real-world subject or system. In this project context, it provides a way to explore how activity-related information may be represented and analysed alongside intelligent modelling techniques.

## Objectives

- Explore Human Activity Recognition in a healthcare and IoHT context.
- Study the role of Artificial Neural Networks in activity recognition.
- Explore Digital Twin concepts for representing a real-world system.
- Use system modelling to understand the components and relationships in the proposed approach.

## Technologies and Concepts

| Technology / Concept | Role |
|---|---|
| **Artificial Neural Networks (ANN)** | Intelligent modelling approach explored for activity recognition |
| **Internet of Healthcare Things (IoHT)** | Connected healthcare context for activity-related data |
| **Digital Twin** | Virtual representation for modelling and analysis |
| **Vensim** | System-dynamics modelling tool used during the project |

## Project Workflow

The project is organised around these high-level stages:

1. Understand the problem of human activity recognition in a healthcare setting.
2. Explore the IoHT context and activity-related information.
3. Study ANN-based approaches for recognising human activities.
4. Explore a Digital Twin representation of the system.
5. Use system modelling to analyse the proposed approach.
